# 0.25.4 (2026-11-28)

## English

Important fix: the selling assistant could suggest a far too low price for gear with a suffix (for example "of Power"), because it did not read the current auction listings. It now reads them correctly and never suggests a price without the current auction minimum.

## Español

Corrección importante: el asistente de venta podía sugerir un precio muy inferior al real con equipo de sufijo (por ejemplo «de poder»), porque no leía los anuncios actuales de la subasta. Ahora los lee bien y nunca sugiere un precio sin el mínimo actual de la subasta.
