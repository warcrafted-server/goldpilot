# 0.17.0 (2026-11-26)

## English

- Settings are defined in one place: the Settings tab is generated from them and `/gpilot set` lists and changes them.
- New "Use prices from the desktop app" setting; when off, GoldPilot ignores the prices that the future desktop app will provide.

## Español

- Los ajustes se definen en un solo sitio: la pestaña Ajustes se genera a partir de ellos y `/gpilot set` los lista y cambia.
- Nuevo ajuste «Usar precios de la aplicación de escritorio»; desactivado, GoldPilot ignora los precios que aportará la futura aplicación de escritorio.
